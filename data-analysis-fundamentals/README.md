# Data Analysis Fundamentals

Coursework applying core data analysis and preprocessing techniques across three datasets, covering attribute classification, descriptive statistics, missing data imputation, feature scaling, dimensionality reduction (PCA), similarity metrics, and sampling methods.

## Structure

| Level | Dataset | Focus |
|---|---|---|
| [Level A](./level-a-titanic) | Titanic (Kaggle) | Attribute types, descriptive statistics, missing data imputation |
| [Level B](./level-b-wine) | Wine (Kaggle) | Normalization/standardization, feature engineering, discretization, PCA |
| [Level C](./level-c-hotel) | Hotel Bookings (Kaggle) | Advanced sampling strategies, data quality analysis |

## Techniques covered
- Attribute classification (nominal, ordinal, discrete, continuous)
- Descriptive statistics & outlier detection
- Missing data imputation (constant, mean/median/mode, predictive/KNN)
- Min-max normalization & Z-score standardization
- Feature creation, binning, one-hot encoding
- Similarity/distance metrics (Euclidean, Jaccard, Cosine, Pearson)
- Manual PCA implementation (NumPy)
- Sampling methods (simple random, stratified, cluster)

## Stack
Python, Pandas, NumPy, Matplotlib/Seaborn
